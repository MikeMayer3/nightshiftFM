- Damage/exposure: keep the main gun leveled, recruit Bass, choose Compression

- Field damage: recruit Static Net, choose Live Current and Surge Current;

intentional. Main gun and shield never take support slots.

Ask the player to explain what the chosen branches changed and why the run ended.

Acceptance needs readable danger, meaningful choices, two winning builds and
interest in another attempt. If those are missing, adjust this loop before M5.
Six sessions provide qualitative feedback, not statistical proof.
